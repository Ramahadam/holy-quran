# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues for
`Ramahadam/holy-quran`. Use the `gh` CLI for issue operations.

## Conventions

- Create an issue with `gh issue create`.
- Read the complete issue body, comments, and labels with `gh issue view`.
- List issues with `gh issue list` and an explicit state or label filter.
- Update labels or content with `gh issue edit`.
- Add progress or decisions with `gh issue comment`.
- Close an issue with `gh issue close` only when its acceptance criteria are met.

When a skill says "publish to the issue tracker," create a GitHub issue. When a
skill says "fetch the relevant ticket," read the complete GitHub issue,
including its comments and labels.
